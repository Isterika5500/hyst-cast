hyst-cast — стрим экрана для своих
==================================

1. Распакуй папку куда угодно (например, на рабочий стол).
2. Запусти hyst-cast.exe. Если Windows скажет «Защитник Windows предотвратил запуск»:
   «Подробнее» → «Выполнить в любом случае» (программа не подписана, это нормально).
3. Введи своё имя и комнату (ту же, что у друзей) → «Войти».

Смотреть: у друга появится «● стримит» → «▶ Смотреть». Откроется окно с видео.
   Alt+Enter — во весь экран. Громкость — ползунок 🔊 в окне hyst-cast.

Стримить: «Что» — экран или окно, «Качество», галочка «Звук системы» → «● Начать стрим».
   Если тормозит у зрителей — выбери качество ниже (720p).

Если что-то не работает — пришли файл
   %APPDATA%\hyst-cast\log.txt
(вставь эту строку в адресную строку Проводника).
